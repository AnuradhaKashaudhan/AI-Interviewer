# Object-Oriented Programming (OOP) Knowledge Base

## Topic: Core Object-Oriented Pillars
- **Domain**: oop
- **Topic**: polymorphism_encapsulation
- **Difficulty**: easy

### Pillars
1. **Encapsulation**: Bundling state data and behavioral methods within a single class while restricting direct access to internal state via access modifiers (private, protected, public).
2. **Abstraction**: Hiding implementation complexity behind simple abstract interfaces.
3. **Inheritance**: Enabling child classes to inherit attributes and behaviors from parent classes.
4. **Polymorphism**: The ability of different classes to respond to the same interface or method call differently.
   - **Compile-time Polymorphism**: Method overloading (same method name, different signatures).
   - **Run-time Polymorphism**: Method overriding (child class providing specific implementation for inherited virtual method).
