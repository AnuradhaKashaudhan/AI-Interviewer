## Topic: React Reconciliation & Virtual DOM
- **Domain**: web_development
- **Topic**: react_reconciliation
- **Difficulty**: medium

### Virtual DOM & Fiber Architecture
React maintains an in-memory Virtual DOM tree representing UI layout. When component state changes, React constructs a new Virtual DOM tree and runs its Reconciliation algorithm (Fiber) to compute minimal DOM mutations before committing updates to the real browser DOM.

## Topic: REST vs. WebSockets
- **Domain**: web_development
- **Topic**: api_architecture
- **Difficulty**: medium

### Protocols
- **REST**: Stateless request-response architecture built over HTTP/HTTPS, utilizing standard verbs (GET, POST, PUT, DELETE).
- **WebSockets**: Persistent full-duplex TCP communication channels for low-latency real-time bidirectional streaming.
