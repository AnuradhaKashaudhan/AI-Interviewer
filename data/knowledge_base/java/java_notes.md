# Java Programming Knowledge Base

## Topic: Java Memory Model & Garbage Collection
- **Domain**: java
- **Topic**: jvm_garbage_collection
- **Difficulty**: hard

### Concepts
Java applications run inside the JVM (Java Virtual Machine). Memory is divided into Heap (Eden, Survivor, Tenured generations) and Stack (stack frames per thread). Garbage collectors (G1GC, ZGC) automatically reclaim unreachable heap memory.
