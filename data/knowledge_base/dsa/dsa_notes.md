### Big-O Notation
Big-O notation quantifies upper bounds on worst-case execution time or memory utilization relative to input size $N$.

### Common Complexities
- $O(1)$: Constant time (hash map lookup).
- $O(\log N)$: Logarithmic time (binary search).
- $O(N)$: Linear time (array iteration).
- $O(N \log N)$: Linearithmic time (Merge Sort, Quick Sort average).
- $O(N^2)$: Quadratic time (Bubble Sort).
